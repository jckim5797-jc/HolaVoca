# 🇪🇸 HolaVoca - 하루 3분 스페인어 단어 트레이닝

> **하루 3분으로 완성하는 스페인어 필수 단어 반복 학습 플랫폼**

HolaVoca는 초보자도 쉽게 스페인어 단어를 외울 수 있도록 양방향 퀴즈와 원어민 발음(TTS)을 제공하는 모던 반응형 웹 애플리케이션입니다.

---

## ✨ 주요 기능

- **양방향 퀴즈 모드**:
  - `스페인어 ➔ 한글 뜻 맞추기 (3지선다)`
  - `한글 뜻 ➔ 스페인어 맞추기 (3지선다)`
- **품사별 카테고리 집중 학습**:
  - 전체 (랜덤)
  - 동사 (Verbos)
  - 명사 (Sustantivos)
  - 전치사 및 접속사 (Preposiciones)
  - 형용사 및 필수 표현 (Adjetivos y Frases)
- **Web Speech API 원어민 발음 (TTS)**: 단어별 실시간 스페인어 발음 듣기 지원
- **게이미피케이션**: 연속 출석 스트릭(🔥), 콤보 및 점수 시스템
- **3문항 학습 성향 진단 설문**: 맞춤 로드맵 추천 및 전체 학습자 통계 그래프 제공
- **반응형 디자인 & 다크 모드**: PC/모바일 최적화 및 테마 전환 기능

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, Tailwind CSS (CDN), Vanilla JavaScript
- **Icons**: Font Awesome 6
- **Hosting**: Cloudflare Pages / GitHub Pages
