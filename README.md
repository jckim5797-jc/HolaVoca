# 🇪🇸 HolaVoca - 하루 3분 5,000단어 스페인어 트레이너

> **일상 회화부터 DELE B2/C1까지! 5,000개 핵심 어휘 완성 플랫폼**

HolaVoca는 하나의 언어를 유창하게 구사하기 위한 핵심 기준인 **5,000개 고빈도 스페인어 단어**를 누구나 쉽고 빠르게 외울 수 있도록 양방향 퀴즈와 원어민 발음(TTS)을 제공하는 오픈형 웹 애플리케이션입니다.

---

## ✨ 주요 기능

- **5,000개 고빈도 스페인어 핵심 어휘 완비**:
  - 📚 **명사 (Nouns)**: 2,524개 (일상, 비즈니스, 사회, 자연, 문화)
  - 🏃 **동사 (Verbs)**: 1,081개 (규칙 및 불규칙 필수 동사 총망라)
  - ✨ **형용사·부사·표현 (Adjectives & Expressions)**: 1,245개 (상태, 감정, 묘사 표현)
  - 🔄 **전치사·접속사 (Prepositions & Conjunctions)**: 150개 (문맥 연결 필수 기능어)
- **100% 바이링구얼 지원 (Korean / English)**:
  - 원클릭으로 한국어(`🇰🇷`) 및 영어(`🇺🇸`) 기반 학습 환경 즉시 전환
  - 전 단어 원어민급 예문 및 다국어 번역 제공
- **양방향 3지선다 퀴즈 모드**:
  - `스페인어 ➔ 뜻 맞추기 (3지선다)`
  - `뜻 ➔ 스페인어 맞추기 (3지선다)`
- **품사별 카테고리 필터링**:
  - 전체 (5,000단어 랜덤)
  - 동사 (1,081)
  - 명사 (2,524)
  - 전치사·접속사 (150)
  - 형용사·표현 (1,245)
- **Web Speech API 원어민 발음 (TTS)**: 단어별 실시간 스페인어 발음 듣기 및 정답 시 자동 재생
- **Web Audio API 게이미피케이션**: 연속 출석 스트릭(🔥), 콤보, 점수 및 키보드 단축키(1, 2, 3, Space) 지원
- **스페인어 심층 학습 가이드 (3편)**: 애드센스 규격 충족 고품질 교육 칼럼
- **3문항 학습 성향 진단 설문**: 맞춤 로드맵 추천 및 실시간 통계 모달 제공
- **다크 모드 & 반응형 UI**: 모바일, 태블릿, PC 완벽 대응
